# API CRUD de Tarefas com Flask

API REST desenvolvida em Python com Flask para gerenciar tarefas.

## Tecnologias utilizadas
- Python
- Flask
- Postman (para testes)
- SQLAlchemy
- SQLite

## Funcionalidades
- Listar tarefas (GET)
- Criar tarefa (POST)
- Marcar tarefa como concluída (PUT)
- Deletar tarefa (DELETE)

## Como rodar o projeto
1. pip install flask flask-sqlalchemy
2. Execute: `python app/main.py`
3. Acesse: `http://127.0.0.1:5000/tarefas`
